API sənədi: backend repo-dakı docs/api-contract.md və <URL>/docs (Swagger). Cavab sahələrinin adları frontend tipləri ilə üst-üstə düşməlidir (types/hotel.ts), fərq varsa yalnız servis qatında mapping et, ekranları dəyişmə.

1) services/api.ts: fetch client, hər sorğuya X-Device-Id (ilk açılışda expo-crypto ilə UUID yarat, expo-secure-store-da saxla), 15 san timeout, xəta formatı ({error:{code,message}}) oxunub istifadəçiyə Azərbaycan dilində mesaj, şəbəkə xətası üçün ayrıca mesaj.
2) @tanstack/react-query: QueryClientProvider; hotelService funksiyalarını (getHotels, getHotelById, getHotelsByIds) imzaları DƏYİŞMƏDƏN real API çağırışları ilə əvəz et. Axtarış vəziyyəti (şəhər, tarix, qonaq, sıralama, filtrlər) query parametrlərinə çevrilsin (city, checkIn, checkOut, guests, sort, minPrice, maxPrice, minStars, amenities, hasDiscount, page, pageSize). Ana səhifədə useInfiniteQuery ilə sonsuz scroll. Şəhər seçimi GET /cities-dən gəlsin.
3) Favorites: ürək düyməsi optimistic update ilə PUT/DELETE /favorites/{hotelId}; ilk açılışda lokal favoritləri POST /favorites/sync ilə serverə göndər; AsyncStorage yalnız offline cache. Favoritlər ekranı GET /favorites.
4) Rezervasiya: POST /bookings (Idempotency-Key = forma açılanda yaradılan UUID, təkrar cəhd eyni açarla). Qiymət və rezervasiya nömrəsi YALNIZ serverin cavabından göstərilsin, client heç bir məbləğ göndərməsin. NO_AVAILABILITY və CANCELLATION_NOT_ALLOWED xətaları aydın Azərbaycan mesajları ilə.
5) Tarixçə: GET /bookings (status filtri ilə segmentlər), ləğv POST /bookings/{id}/cancel. Profil: GET/PUT/DELETE /profile; rezervasiya formasının avtomatik doldurulması profil API-dən gəlsin (documentNumber maskalanmış qayıdır, redaktədə yenidən daxil edilməsi tələb olunsun).
6) Loading (skeleton), xəta (retry), boş vəziyyət və offline banner bütün ekranlarda real API ilə işləsin. data/hotels.ts mock faylını silmə, yalnız EXPO_PUBLIC_USE_MOCK=1 olduqda istifadə olunsun.
7) Yoxlama: tsc və lint xətasız; real serverə qarşı əsas axın (siyahı → filtr → detal → favorit → rezervasiya → tarixçə → ləğv → profil avtodoldurma) işləyir, nəticəni qısa yaz.
